## How I build

I use AI as an engineering accelerator inside explicit software-development controls rather than as a substitute for them. My workflow combines persistent steering, coding and architecture standards, specifications, MCP-connected development tools, automated hooks, deterministic tests, branch review, and CI/CD gates.

The goal is to make the expected engineering behavior part of the development environment itself: project conventions are defined up front, implementation is checked continuously, tests run as part of task completion, and delivery follows repeatable branch and deployment rules. This lets AI-assisted development move quickly while keeping the output reviewable, testable, and consistent.
